## 一、总览：知识原子的一生（三状态）

> 读法：**横轴是时间**。笔记出生在收件箱 → 被整理进迭代区 → 在迭代区反复"训练" → 考过了晋升到已掌握；哪天被现实打脸（遇到反例），再丢回去重训。

```mermaid
stateDiagram-v2
    direction LR
    [*] --> 收件箱: 随手笔记进入
    收件箱 --> 迭代中: 整理收件箱 → 建四件套（新概念）
    收件箱 --> 迭代中: 整理收件箱 → 归并进已有原子（碎片）
    迭代中 --> 迭代中: 反复 K-Loop（试差因改验）
    迭代中 --> 已掌握: 收敛判据全满足 + 用户确认
    已掌握 --> 迭代中: 遇到反例 / 新场景，丢回重训
```

| 状态 | 位置 | 含义 |
| :-- | :-- | :-- |
| 📥 收件箱 | `00-收件箱/` | 未入环的原料，还没开始训练 |
| 🧬 迭代中 | `10-知识原子/<概念>/` | 四件套在此，反复迭代"长身体" |
| 🏆 已掌握 | `30-已掌握/<概念>/` | 考过收敛判据，归档（四件套保留） |

## 二、入口：收件箱 → 入环（「整理收件箱」skill 怎么分类）

```mermaid
flowchart TD
    INBOX["00-收件箱 里的笔记"] --> Q{先扫已有原子<br>判断这是哪种?}
    Q -->|新概念 · 自成一体| NEW[建四件套原子<br>10-知识原子/概念/]
    Q -->|碎片 · 已有原子的补充| MERGE[归并进对应原子]
    Q -->|疑问 · 是一个问题| MOVE[移入 疑问区]
    Q -->|无用 · 重复失效| DEL[删除<br>需你确认]
    Q -->|拿不准| ASK[问你<br>不擅自归类]
    NEW --> LOOP[[进入 K-Loop 迭代]]
    MERGE --> LOOP
```

> 铁律：**归并优先于新建**，避免知识原子越拆越碎。

## 三、核心循环：K-Loop 一轮（细看）

```mermaid
flowchart TD
    A[1️⃣ 试<br>动手用 / 讲给别人] --> B[2️⃣ 差<br>找一条明确落差]
    B --> C[3️⃣ 因<br>归因到笔记具体位置]
    C --> D[4️⃣ 改<br>更新笔记 版本+1<br>写一条迭代日志]
    D --> E{5️⃣ 验<br>关书重建}
    E -->|❌ 卡壳| C
    E -->|✅| F{收敛判据<br>三条全满足?}
    F -->|否 · 继续练| A
    F -->|是| G[建议晋升<br>→ 30-已掌握]
    C -. 连续 3 轮落差不降<br>密语「刹车」.-> X[回到第一性原理<br>重新拆解]
```

**收敛判据（要全满足才晋升）：**
1. 重建稿**连续 2 次 ✅** 且零参考
2. 压缩版**一页纸、准确无损**
3. 教授稿**新手能复述**

> 回跳规则速记：
> - 重建 ❌ → 回第 3️⃣ 步「因」重新归因
> - 收敛不满足 → 回第 1️⃣ 步继续练
> - 落差不降 3 轮 → 密语「刹车」→ 回第一性原理拆解
> - 某轮跳了步骤 → 密语「违规」→ 回退缺口重做

## 五、什么时候"动"？转移条件速查

| 从 | 到 | 触发条件 | 谁执行 |
| :-- | :-- | :-- | :-- |
| `00-收件箱` | `10-知识原子` | 「整理收件箱」分类并确认 | AI 建议 + 你确认 |
| `10-知识原子` | `10-知识原子`（版本+1） | 一轮 K-Loop 完成 | AI 更新 + 你提供落差 |
| `10-知识原子` | `30-已掌握` | 三条收敛判据全满足 | AI 建议 + 你确认 |
| `30-已掌握` | `10-知识原子` | 遇到反例 / 新场景 | 你触发（文件夹移回去） |

> 记忆口诀：**收件箱 → 迭代区 → 已掌握**，来回路就三条——**入环、晋升、回炉**。
