# 📜 知识迭代协议 · K-Loop 五步法

> **版本：v1.0** · 灵感来源：Andrej Karpathy 的「从零构建 / 训练循环」哲学
> 定位：本系统的**核心方法论**。模板、仪表盘、Skill 都围绕本协议运转。

---

## 🧠 核心哲学

> **读过 ≠ 理解，记住 ≠ 会用。**
> 理解的唯一证明，是**关书之后还能从零重建**；学习的唯一推进方式，是像训练模型一样——**尝试 → 找落差 → 归因 → 更新 → 再验证**。

本协议把知识当作一个「模型」来训练。每个知识点 = 一个**知识原子**，每一轮迭代 = 一个 **epoch**。收敛（overfit 到"真懂"）后晋升为「已掌握」。

---

## ⚡ 触发与分级

| 场景 | 处理 |
| :-- | :-- |
| 🟢 **轻量**：对单个已拆好的概念做一轮迭代 | 直接走 K-Loop 五步法 |
| 🔴 **重量**：陌生领域 / 概念没拆透 / 反复落差不降 | **先做第一性原理拆解**（拆到原子），再走五步法 |
| 📥 **收件箱有新捕获** | 用「整理收件箱」skill 批量处理：新概念 → 建原子笔记入循环；是碎片 → 归并到已有原子 |

## 🔬 第一章：K-Loop 五步法（一轮迭代）

每一轮迭代**必须按顺序走完五步**，缺一步都不算迭代：

### 1️⃣ 试 · 前向（Forward）
**动作**：动手使用/解释这份知识。做题、写代码、讲给别人听、做一个小项目、写一段示例。
**产出**：一次真实尝试记录。
> ⛔ 红线：没有尝试，不算迭代。光"读了一遍"禁止进入下一步。

### 2️⃣ 差 · 损失（Loss）
**动作**：收集现实反馈。哪里卡住？哪里错了？哪里和预期不符？现实给你的"错误信号"就是你的 loss。
**产出**：一条明确的**落差**，用一句话写清："我本以为 X，实际发现 Y"。
> ⛔ 红线：每轮必须产出一条落差，否则本轮无效。

### 3️⃣ 因 · 反向归因（Backprop）
**动作**：把落差**追溯到笔记里的具体位置**——是哪个假设错了？哪个原子没拆透？哪条推导链断了？
**产出**：归因结论 + 证据。归因必须**落到一句话/一个词**，禁止笼统说"我还没理解"。
> 训练隐喻：loss 必须 backprop 到具体的权重上，才有更新价值。

### 4️⃣ 改 · 更新（Update）
**动作**：修正笔记——纠错、补全、重拆、压缩。版本号 +1，写一条迭代日志。
**产出**：更新后的主笔记（`<概念名>.md`）+ `20-迭代日志/概念-日期.md`。
> 压缩方向：每轮都要让「一句话直觉」更短更准。

### 5️⃣ 验 · 重建测试（Eval）
**动作**：**关书**，从零重建。用 `重建稿.md` 把整个概念写下来，不看任何资料。
**产出**：重建稿 + 结果判定。
- ✅ 通过 → 记入重建记录表，检查是否满足收敛判据。
- ❌ 失败 → 把卡壳点写回主笔记的「落差记录」，**回到第 3 步重新归因**。

---

## 🔒 第二章：红线清单（不可违反）

1. **不背结论，必须能推**。任何结论都要能从第一性原理推导出来，否则记为「待拆解」。
2. **每轮必须有落差**。没有落差的一轮，是自我感动，不算迭代。
3. **重建必须关书**。偷看资料的重建，等于没有验证。
4. **压缩不得失真**。压缩 = 去冗余，不是删关键细节。
5. **未过验证不得标记「已掌握」**。状态变更只能由「验」步骤触发。

---

## 🏆 第三章：收敛判据与晋升

当**全部**满足时，概念收敛：

- [ ] **重建稿**：连续 **2 次** ✅ 且零参考
- [ ] **压缩版**：一页纸、准确无损
- [ ] **教授稿**：能让一个完全不懂的人听懂并复述

> 每个知识原子 = 一个文件夹，主笔记**以概念名命名**（`<概念名>.md`），配 `重建稿.md` / `压缩版.md` / `教授稿.md`。

**晋升流程**：
1. 在主笔记标注 `状态: 已掌握`
2. 把整个概念文件夹从 `10-知识原子\` **移入** `30-已掌握\`
3. 在仪表盘登记晋升日期

> 已掌握 ≠ 终点。它只是说明"当前认知通过验证"。未来遇到反例，把它丢回迭代区重新训练。

## 🛑 第四章：自检 · 违规 · 刹车

### 每轮自检清单（做完逐项打勾）
- [ ] 有真实尝试记录（试）
- [ ] 有一条明确落差（差）
- [ ] 归因落到笔记具体位置（因）
- [ ] 版本号已 +1、迭代日志已写（改）
- [ ] 关书重建已完成（验）

### 密语「违规」
当某轮跳过了归因或重建测试，回复 **「违规」**，系统必须：
1. 回退本轮未完成的部分
2. 从缺口步骤重新开始（不得狡辩）

### 密语「刹车」
当连续迭代 **3 轮以上**落差值不下降（在同一处反复卡壳），发送 **「刹车」**，系统必须：
1. 停止打补丁式迭代
2. **回到第一性原理**：重新拆解该概念，寻找缺失的原子或错误的推导链
3. 必要时把概念降级回「收件箱/待拆解」状态

> 训练隐喻：loss 不降 = 学习率失效 / 模型结构错了。继续"刷题"没用，得改结构。
